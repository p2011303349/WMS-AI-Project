# 仓库操作规范

## 入库操作规范

### 收货流程
1. 核对ASN单与实物是否一致
2. 检查外包装是否完好
3. 清点数量，记录差异
4. 扫描商品条码，录入系统
5. 打印收货标签，粘贴在商品上

### 质检标准
- 电子产品：功能测试、外观检查
- 食品：保质期检查、包装完整性
- 服装：尺寸核对、瑕疵检查

### 上架规范
- 按照系统推荐的货位上架
- 重物放底层，轻物放高层
- 同款商品集中存放
- 上架后扫描货位码确认

## 出库操作规范

### 拣货规范
- 按照系统规划的路径拣货
- 拣货时核对SKU和数量
- 使用PDA扫描确认
- 异常情况及时上报

### 打包规范
- 根据商品特性选择合适的包装材料
- 易碎品使用气泡膜包裹
- 液体商品使用防漏包装
- 称重并录入系统

### 发货规范
- 核对快递单与订单信息
- 扫描快递单号关联订单
- 按时发货，更新物流状态

## 盘点操作规范

### 盘点周期
- 重点商品：每月盘点
- 普通商品：每季度盘点
- 年度大盘点：每年12月

### 盘点流程
1. 生成盘点任务
2. 打印盘点表
3. 分区进行实物盘点
4. 录入盘点数据
5. 处理差异（盘盈/盘亏）

## 设备操作规范

### PDA使用
- 使用前检查电量
- 保持扫描头清洁
- 轻拿轻放，防止跌落
- 每日充电，定期同步数据

### 标签打印机
- 定期清洁打印头
- 使用合格标签纸
- 注意碳带安装方向
- 及时更换耗材

## 安全规范

### 消防安全
- 仓库内禁止吸烟
- 消防通道保持畅通
- 灭火器定期检查
- 易燃品单独存放

### 作业安全
- 高货架使用登高车
- 重物使用叉车搬运
- 佩戴安全帽和反光衣
- 注意货架承重限制

### 信息安全
- 系统账号专人专用
- 定期修改密码
- 不泄露系统操作权限
- 离开工位及时锁定电脑
